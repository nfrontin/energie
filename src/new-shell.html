Comprendre les calculs et les données

Relevés Home Assistant conservés dans VictoriaMetrics, avec un pas de 5 minutes. Les volumes horaires sont calculés par différence des index ; les remises à zéro sont prises en compte. La dernière valeur connue est conservée entre les relevés, pendant 30 jours au maximum. Une donnée manquante s’affiche « — ». Les valeurs peuvent différer légèrement des statistiques horaires de Home Assistant.

Maison = réseau acheté + production solaire − injection. Solaire consommé = production − injection. Autoconsommation = solaire consommé / production ; autonomie = solaire consommé / consommation maison. Les tarifs sont synchronisés avec Home Assistant, hors abonnement et taxes additionnelles. Les changements sont historisés à partir de leur première observation ; les coûts antérieurs utilisent le premier tarif connu. Lors d’un changement en cours d’heure, le coût est estimé au prorata de sa durée. La veille est une journée complète, même lorsque la journée sélectionnée est encore en cours.
